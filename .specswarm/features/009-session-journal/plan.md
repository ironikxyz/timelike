## Summary

- **The reader:** one new agent tool, **`tools/bin/journal`**. It reads a session's tool events (001),
  its shell record (new, this feature's own writer) and, for the operator, Adele's ledger rows piped in.
  It prints one ordered, linked, redacted timeline, by session and agent (spec FR-1 to FR-14).
- **The writer:**
  - one guarded step in 001's bash hook sets an EXIT trap;
  - the trap sources `/etc/timelike/journal-exit.bash`, which appends one JSON line per `bash -c` /
    `bash -lc` command (R1, measured).
- **The extension to 001's event:** `agent`, `ppid`, `ref`, `t_ms`, all optional (R2).
